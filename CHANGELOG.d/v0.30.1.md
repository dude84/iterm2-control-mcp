# v0.30.1

Internal release — no user-visible changes to MCP tools, CLI, or file layout.

## Development workflow

- Development is now consolidated on this public repository; the previous private dev mirror has been retired.
- `CLAUDE.md` documents the single-repo release flow.

## Build

- `mcpb/build.sh` no longer mutates the committed `manifest.json` during `.mcpb` builds. The patched version is written in place during `mcpb pack` and restored on exit (success or failure) via a trap, with `ensure_ascii=False` so non-ASCII characters in the manifest round-trip cleanly. Running `make mcpb` now leaves the working tree unchanged.

## Meta

- Hand-authored release notes live under `CHANGELOG.d/vX.Y.Z.md`, referenced via `gh release create --notes-file`.
