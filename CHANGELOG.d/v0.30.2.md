# v0.30.2

## Fixes

- **Commands now execute on Windows `cmd.exe` hosts** ([#11](https://github.com/dude84/iterm2-control-mcp/issues/11)). `iterm_send_command`, `iterm_send_and_read` and `iterm_send_keys("enter")` submitted lines with LF (`\n`). Windows `cmd.exe` / ConPTY (e.g. over OpenSSH) ignores a lone LF, so commands were typed onto the prompt but never ran. Lines are now submitted with CR (`\r`), exactly what the Return key sends. Unix shells are unaffected — the tty maps CR to NL as before.

## Known limitations on Windows hosts

- `command_markers` echoes a `# [ai]` line before each command; `cmd.exe` does not treat `#` as a comment and prints an error for it.
- `iterm_upload_file` and `iterm_download_file` rely on POSIX `base64`, here-docs and `printf`, and do not work in `cmd.exe`.

## Build

- Release workflow actions bumped to their Node 24 versions: `actions/checkout` v7.0.0, `actions/setup-python` v6.3.0, `actions/setup-node` v6.4.0, `softprops/action-gh-release` v3.0.1, `actions/attest-build-provenance` v4.1.1. GitHub removed Node 20 from Actions runners on 2026-09-16.
